  # AI Agents in Networking

  A fast-growing category: LLM-powered agents applied to network operations —
  troubleshooting, configuration, change management, and observability.

  ## Directories & Field Guides

  * [NetAgents](https://netagents.ai) — a hand-checked directory of vendor and
    open-source agentic AI tools for networking, plus long-form articles on
    the space.

  ## Core Concepts

  * [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — the
    emerging standard for connecting LLMs to external tools and data sources,
    including network device/API access.
  * [Building Effective AI Agents](https://www.anthropic.com/research/building-effective-agents)
    (Anthropic) — a solid primer on agent design patterns that applies
    directly to network automation use cases.
